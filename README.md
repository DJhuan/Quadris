# Quadris

Uma modificação maluca com quatro gravidades para o clássico jogo russo!

---

## Como jogar

O objetivo é formar fileiras contínuas de 10 blocos dentro da área jogável para acumular o máximo de pontos possível.

O jogador move as peças usando as setas ou `W A S D`. Para rotacionar a peça a favor do relógio ou contra o relógio, basta usar `E` ou `Q`, respectivamente. Lembre-se, uma peça nunca pode atravessar o tabuleiro, caso contrário, você perde.

## Tecnologias utilizadas

O Jogo foi feito usando HTML, CSS e JavaScript. O destaque aqui vai para o componente `<canvas>` do HTML, que tornou o jogo possível.

> ⚠️ AVISO: para além das tecnologias mencionadas, o autor contou com auxílio de inteligência artificial para criação do código, especialmente para a colisão e desenho dos gráficos no elemento `<canvas>`.
